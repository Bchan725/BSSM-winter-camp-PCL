### 개요

본 문서는 부산소마고 동계 캠프 강의 교육 자료를 설명하기 위해 작성되었으며, 시간별 진행 순서는 다음과 같습니다.

1. Cpp
2. Ros2
3. Ply

### 환경 설정 방법

다음 방법을 통해 실습 가상 환경에 Ros2 개발 환경을 구축할 수 있습니다.

**( 단, 현 프로젝트를 Clone 받았다고 가정하고 진행합니다. )**

```
$ cd scripts/

$ sudo chmod +x *

$ ./install_ros2.sh && ./install_cmake.sh

```
